# Componente de código QR

Mi solución al reto [QR code component](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) de Frontend Mentor: una tarjeta sencilla con un código QR, maquetada a partir del diseño en móvil y escritorio.

![Vista previa del diseño](./design/desktop-preview.jpg)

## Demo

La web se publica con GitHub Pages en cada push a `main`: https://menendezpa.github.io/QR/

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox), adaptado a móvil y escritorio
- GitHub Actions para el despliegue en GitHub Pages

## Qué he practicado

- Pasar un diseño estático (JPG) a HTML y CSS ajustando tamaños, márgenes y tipografía a ojo.
- Centrar contenido y usar la guía de estilos (`style-guide.md`) para colores y fuentes.
- Automatizar el despliegue con un workflow de GitHub Pages.
